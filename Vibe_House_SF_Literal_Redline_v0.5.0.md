# Vibe House SF — Proposed Copy Changes

This is the **literal copy review** requested. Each block shows the current website text, a redline, and the clean replacement that would be pasted into the site. The underlying direction is simple: Vibe House is an unusually thoughtful environment for distinctive gatherings, post-exit possibility, generous exchange, and deeper connection. It should not read like a coworking space, a wellness claim, or a status club.

| Page / URL | What changes |
|---|---|
| `/` | Reframes the house around events, meaningful encounters, and the atmosphere that allows generosity to emerge. |
| `/why` | Moves from an AI productivity race toward the post-exit experience and the value of gathering in the right room. |
| `/events-series` | Makes each series a distinct kind of conversation held in the same intentional house. |
| `/biological-founder` | Reframes the environment as care and hospitality rather than performance or medical optimization. |
| `/the-founders-pharmacy` | Reframes products as what makes the house comfortable and welcoming, without broad health promises. |
| `/brand` | Defines a voice that is warm, discerning, and human—not transactional, exclusive, or inflated. |
